## 实验复现
### 实验环境
一张 A100 40GB；
生成模型使用 Qwen/Qwen2.5-VL-7B-Instruct

### 下载源码并解压
```bash
curl --http1.1 -L \ --retry 20 \ --retry-all-errors \ --retry-delay 3 \ --connect-timeout 30 \ --speed-time 120 \ --speed-limit 1024 \ --progress-bar \ -o ViDoRAG-main.zip \ https://codeload.github.com/Alibaba-NLP/ViDoRAG/zip/refs/heads/main

ls -lh ViDoRAG-main.zip 
file ViDoRAG-main.zip 
unzip -t ViDoRAG-main.zip | tail
```

### 创建独立环境
```bash
cd /data/fyx/ViDoRAG_work/ViDoRAG
conda create -n vidorag python=3.10 -y
conda activate vidorag
# 确认环境
which python
python --version
```

### 固定使用空闲的 GPU0
```bash
export CUDA_VISIBLE_DEVICES=0
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True

export HF_HOME=/data/fyx/ViDoRAG_work/hf_cache
export TRANSFORMERS_CACHE=$HF_HOME/hub

mkdir -p "$HF_HOME"
```

### 安装 Pytorch
```bash
python -m pip install --upgrade pip wheel
python -m pip install setuptools==79.0.1

python -m pip install \
  torch==2.5.1 \
  torchvision==0.20.1 \
  --index-url https://download.pytorch.org/whl/cu124
```

python - <<'PY'
import torch

### 整理并安装项目依赖

官方 requirements.txt 需要锁定几个关键版本，避免 torchvision 或 transformers 被升级到不兼容版本。官方依赖包含 ColPali Engine、Transformers 4.49 以上、LlamaIndex 0.12 等。

```bash
# 先生成约束文件
cat > constraints.txt <<'EOF'
torch==2.5.1
torchvision==0.20.1
transformers==4.49.0
colpali-engine==0.3.2
qwen-vl-utils==0.0.10
setuptools==79.0.1
EOF
```
