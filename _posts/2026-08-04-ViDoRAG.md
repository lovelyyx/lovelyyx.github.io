### 整理并安装项目依赖

官方 requirements.txt 需要锁定几个关键版本，避免 torchvision 或 transformers 被升级到不兼容版本。官方依赖包含 ColPali Engine、Transformers 4.49 以上、LlamaIndex 0.12 等。

```bash
# 先生成约束文件
cat > constraints.txt <<'EOF'
torch==2.5.1
torchvision==0.20.1
transformers==4.49.0
colpali-engine==0.3.2
qwen-vl-utils==0.0.10
setuptools==79.0.1
EOF

# 将官方 requirements 中的空格统一转换成换行，并排除已经安装的 PyTorch：
tr ' ' '\n' < requirements.txt \
  | sed '/^[[:space:]]*$/d' \
  | grep -vE '^(torch==|torchvision$)' \
  > requirements.no_torch.txt

# 安装
python -m pip install \
  -r requirements.no_torch.txt \
  -c constraints.txt

# 补充仓库运行时会用到、但 requirements.txt 中没有明确列全的依赖：
python -m pip install \
  accelerate \
  pdf2image \
  pillow \
  openai \
  -c constraints.txt

# 安装 PDF 转图片工具（将 PDF 渲染成页面图片）
conda install -c conda-forge poppler -y

# 完成环境自检
python - <<'PY'
import torch
import transformers
import sklearn
import llama_index
import colpali_engine
import qwen_vl_utils
import pdf2image
from PIL import Image

print("========== Environment ==========")
print("torch:", torch.__version__)
print("CUDA runtime:", torch.version.cuda)
print("CUDA available:", torch.cuda.is_available())
print("transformers:", transformers.__version__)
print("sklearn:", sklearn.__version__)
print("colpali_engine: imported")
print("qwen_vl_utils: imported")
print("llama_index: imported")
print("pdf2image: imported")

if torch.cuda.is_available():
    print("GPU:", torch.cuda.get_device_name(0))

print("========== CHECK PASSED ==========")
PY
```

## 问题
### 1.依赖冲突

ImportError: /data/wangyuxiang/conda_envs/vidorag/lib/python3.10/site-packages/torch/lib/../../nvidia/cusparse/lib/libcusparse.so.12: undefined symbol: __nvJitLinkComplete_12_4, version libnvJitLink.so.12

>libcusparse.so.12

>需要 CUDA 12.4 版本的 libnvJitLink.so.12

>但系统实际先加载了旧版本 libnvJitLink.so.12

```bash
python -m pip install \
  --force-reinstall \
  --no-cache-dir \
  --no-deps \
  nvidia-nvjitlink-cu12==12.4.127 \
  nvidia-cusparse-cu12==12.3.1.170
```

> 可以在这里放一句重点内容。
