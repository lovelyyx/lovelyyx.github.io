Markdown 写作快速入门

2024.07.27学习约 3 分钟

Markdown 是一种轻量级标记语言。只需要记住少量符号，就能把注意力放回内容本身。

常用语法

标题

# 一级标题
## 二级标题
### 三级标题

强调与链接

**粗体文字**
*斜体文字*
[链接名称](https://example.com)

列表

- 第一项
- 第二项
- 第三项
写作时先把内容写完，再调整结构。不要让格式打断表达。

一篇文章的简单结构

  1. 用开头说明文章要解决什么问题
  2. 把核心内容拆成几个小标题
  3. 加入示例、截图或代码
  4. 最后总结关键结论

掌握这些内容后，就已经足够开始写第一篇 Markdown 文章了。
